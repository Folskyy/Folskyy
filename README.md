### Research & Current Interests

**Text-to-SQL & Natural Language Database Interfaces**

My main research direction focuses on translating natural language into executable SQL through modular, context-aware LLM pipelines.

I'm particularly interested in:

- Schema understanding, context selection, and semantic grounding.
- Modular architectures for SQL generation and validation.
- Query correctness, consistency, and reproducible evaluation.
- Role-aware database access and security constraints.
- Observability and reliability of LLM-driven database systems.

**Beyond Text-to-SQL**

I also explore **Mixture-of-Experts (MoE)** architectures, semantic and adaptive routing, and the intersection of machine learning with control and embedded systems.
